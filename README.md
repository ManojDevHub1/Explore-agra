# Explore Agra – A Simple Travel Guide

A beginner-friendly tourism website about Agra, created as part of my web development learning journey.

## Project Overview

**Explore Agra – A Simple Travel Guide** is a simple tourism website that introduces visitors to popular places, local food, travel information, travel tips, and frequently asked questions about Agra.

I first created this project using **HTML only** and then upgraded it by adding an external **CSS** file.

The main purpose of this project is to practice HTML and CSS fundamentals by building a complete website.

## Day 1 – HTML

On Day 1, I built the basic website structure using HTML5.

### HTML Concepts Practiced

- Basic HTML document structure
- Headings and paragraphs
- Links
- Images and `alt` text
- Ordered and unordered lists
- Tables
- Forms
- Semantic HTML
- Internal page navigation
- `<details>` and `<summary>`
- Basic form elements

## Day 2 – CSS

On Day 2, I added an external `style.css` file to improve the appearance of the same website.

### CSS Concepts Practiced

- Colors

- Font styling
- Text alignment
- Margin
- Padding
- Borders
- Border radius
- Width

The goal was to understand how CSS can change the presentation of an existing HTML structure.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and the `Emage` folder are in the correct locations.
4. Open `index.html` in a web browser.

No installation is required.

## What I Learned

This project helped me understand an important difference:

**HTML provides the structure, while CSS controls the appearance and presentation.**

Working on the same website across Day 1 and Day 2 helped me see how CSS can improve a plain HTML page without changing its basic structure.
