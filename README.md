# Explore Agra – A Simple Travel Guide

A beginner-friendly tourism website about Agra, created as my first complete HTML website project.

## About the Project

**Explore Agra** is a simple travel guide that introduces visitors to some popular places, food, and basic travel information about Agra.

I created this project while learning the fundamentals of HTML and practicing how different HTML elements work together to build a complete webpage.

## Features

- Simple navigation menu
- Introduction to Agra
- Popular places to visit
- Agra food section
- Travel information table
- Travel tips
- FAQ section using `details` and `summary`
- Simple contact form
- Images with alternative text
- Semantic HTML structure

## Technologies Used

- HTML5

> No CSS, JavaScript, Bootstrap, Tailwind, or external libraries were used in this project.

## HTML Concepts Practiced

This project helped me practice:

- Headings and paragraphs
- Links
- Images
- Ordered and unordered lists
- Tables
- Forms
- Semantic elements
- `details` and `summary`
- Page navigation with links
- Basic HTML structure

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No installation or setup is required.
